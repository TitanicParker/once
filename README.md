# Clinical Documentary Case — Flat Repository v2

**Canonical source:** `complete-record.md` (CLIN-000001–CLIN-003289).

## Evidential chain

**Complete record → Timeline → Facts → Tensions → Propositions → Expert Questions → Management Plan → Reliability → Adversarial Survival → Clinical Argument**

This repository is evidence-first. It does not assume that structural foot disease was neurological, that Podiatry was inappropriate, that levodopa should have started in 2017, or that medication response proves pain mechanism.

## Control rules

1. Structural pathology, pain, anatomical site, dystonia/posture/loading, Parkinsonian motor state, neuropathic hypotheses, medication-state modulation, patient interpretation, clinician interpretation, treatment decision, treatment response and retrospective explanation are separate variables.
2. Treatment response establishes **modifiability**, not mechanism.
3. Later PRKN confirmation cannot be back-projected into 2017 clinical knowledge.
4. The original April 2017 bilateral pain is not retro-localised to the later left fifth-MTPJ lesion.
5. The recurrent left fifth-MTPJ/outside-left signal is preserved without turning every later pain syndrome into the same lesion.
6. Local management change is not treated as proof of global reassessment.
7. Later retrospective accounts are audited against contemporaneous sources and may be reliable, compressed, selective or reconstructive proposition by proposition.
8. Absence of a documented global reassessment does not prove no mental or undocumented reassessment occurred.

## Core issue

The strongest case is not that one original diagnosis was simply wrong. It is whether an expressly unresolved mixed structural–neurological problem became organised into durable parallel pathways, and whether later cross-domain evidence was adequately used to reopen that architecture rather than being accommodated through successive local treatment changes.
